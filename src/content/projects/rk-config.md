summary: >-
  A fork of KludgeKnight (open source, GPL-3.0) for remapping keys and
  lighting on Royal Kludge keyboards, straight from a desktop Chrome, Edge or
  Opera browser over USB. I added per-key colours with two editable palettes,
  modifier chords such as Command + C on a single key, and separate Apply and
  Discard for key mapping and lighting, so nothing reaches the keyboard until
  you confirm. Each model's keyboard is drawn in code from Royal Kludge's own
  key data, and every model shows how well each feature is actually
  verified. A demo mode lets anyone try it without a keyboard. Unofficial;
  not affiliated with Royal Kludge.
